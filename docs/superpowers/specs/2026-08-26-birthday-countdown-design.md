# 生日与纪念日倒计时 Android App 设计规格

日期：2026-08-26

## 1. 产品目标

提供一个离线优先的 Android App，让用户用方框卡片查看生日和纪念日的实时计时，并在周年到来前收到本地提醒。

## 2. 已确认范围

- 首期仅支持 Android。
- 不需要账号、网络服务或多设备同步，数据保存在本机。
- 支持一条生日记录，以及多条可新增、编辑、删除的纪念日记录。
- 生日按年自动计算下一次生日。
- 纪念日同时显示已持续时长，以及距离下一个周年的倒计时。
- 日期和时间精确到秒，使用 24 小时制。
- 全局日期格式可切换：
  - 中文完整格式：`2026 年 5 月 23 日 08 时 35 分 46 秒`
  - 数字格式：`2026/05/23 08:35:46`
- 每条记录可独立开启提醒并设置提前时间；生日和纪念日都按周年重复提醒。
- 每条记录可单独选择阳历或阴历；阴历支持闰月，目标年份无对应闰月时按同月普通月份处理。
- 卡片显示所选历法，并附自动换算后的另一种历法日期。

## 3. 用户界面

### 首页

- 顶部显示页面标题和“添加卡片”按钮。
- 下方以方框卡片列表展示记录，卡片包含名称、日期时间和计时结果。
- 生日卡片显示距离下一次生日的天、小时、分钟、秒。
- 纪念日卡片显示“已经持续多久”和“下一个周年还有多久”。
- 点击卡片进入编辑；卡片菜单提供删除。
- 无记录时显示添加第一条记录的空状态。

### 添加/编辑页

- 记录类型：生日或纪念日。
- 名称输入。
- 日期选择器和时间选择器，精确到秒，24 小时制。
- 提醒开关和提前时间选择。
- 生日记录只允许一条；再次设置生日时进入编辑已有生日。

### 设置页

- 全局日期格式切换。
- 默认提醒开关和默认提前时间。

## 4. 计时规则

- 使用设备本地时区和系统当前时间。
- 生日目标时间：将出生日期的月、日和设定时间映射到当前年份；若已过去，则计算到下一年。
- 纪念日目标时间：首次目标为开始日期时间。目标未到时只显示剩余倒计时；目标到达后显示已持续时长，并计算下一个周年目标。
- 年、月、日的持续时长使用日历运算；小时、分钟、秒使用时间差运算，避免把一个月固定折算成天数。
- 首页计时器每秒刷新；App 进入后台时停止 UI 刷新，回到前台重新基于当前时间计算，不依赖累计 tick。

## 5. 技术架构

- 语言：Kotlin。
- UI：Jetpack Compose。
- 本地数据：Room；单一数据库表保存记录和提醒配置。
- 状态：ViewModel + Kotlin StateFlow。
- 本地提醒：AlarmManager 设置精确的周年提醒；触发后由 BroadcastReceiver 发布通知，并安排下一年的提醒。
- 时间类型：`java.time.LocalDateTime`、`ZonedDateTime` 和 `ZoneId.systemDefault()`。

主要模块：

- `data`：Room Entity、DAO、数据库和数据仓库。
- `domain`：生日/周年目标日期计算与计时格式化。
- `ui.home`：卡片列表和每秒刷新状态。
- `ui.edit`：新增、编辑和删除流程。
- `ui.settings`：格式与默认提醒设置。
- `notifications`：提醒调度、接收和取消。
- `domain/LunarCalendarConverter`：基于 Android ICU ChineseCalendar 的阴阳历转换。

## 6. 错误与边界处理

- 名称为空时禁止保存。
- 日期时间必须有效；系统不接受不存在的日期。
- 删除前显示确认操作，避免误删。
- 日期格式设置立即作用于所有卡片。
- 闰年生日在非闰年按产品统一规则处理为 2 月 28 日目标，避免没有目标日期。
- 用户修改系统时区后，重新计算目标时间并重排提醒。

## 7. 测试与验收

- 单元测试：下一次生日计算、未来/过去纪念日、周年跨年、闰年、时区变化和格式化。
- UI 测试：新增、编辑、删除、格式切换、空状态和卡片展示。
- 通知测试：提醒开关、提前时间、周年重复调度和取消。
- 手工验收：关闭并重启 App 后数据保留；等待至少一分钟确认秒级倒计时变化；修改系统时间验证边界行为。

## 8. 非目标

- 首期不做账号体系、云同步、社交分享、桌面小组件、广告和复杂主题系统。
