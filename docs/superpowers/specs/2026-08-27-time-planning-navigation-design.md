# 时间规划局界面与个性化改造设计

## 目标

将现有生日倒计时单页应用改造成“时间 / 添加时间 / 我的”三入口应用，同时改善卡片编辑、颜色输入、卡片排序和应用品牌展示。保留现有生日、纪念日、阳历、农历、提醒和倒计时算法。

## 主导航

- 底部固定三个位置：时间、添加时间、我的。
- 默认使用线性图标加小文字，选中项通过主题色和轻量指示器区分。
- “时间”显示倒计时卡片列表；移除原右下角悬浮添加按钮。
- “添加时间”是独立完整页面，可新建生日或纪念日；保存后返回“时间”。
- “我的”展示设置入口，原全局设置迁移到这里。
- 编辑已有卡片仍从“时间”页点击卡片进入，完成后返回“时间”。

## 底部导航个性化

- 在“我的 -> 设置 -> 底部导航设置”中分别配置三个入口。
- 每个入口可修改小文字、从内置线性图标集合更换图标，并分别隐藏图标或文字。
- 同一入口的图标和文字不能同时隐藏；操作会导致同时隐藏时，界面阻止该操作并保留最近一个可见元素。
- 提供恢复默认按钮。
- 配置使用 SharedPreferences 持久化，重启后保留。
- 三个入口的位置和实际功能固定，避免自定义文字或图标破坏导航路由。

## 卡片列表与排序

- 卡片按持久化的 `sortOrder` 升序显示。
- 长按卡片空白区域后可上下拖动，删除按钮及其他操作控件不启动拖动。
- 拖动期间显示轻微抬升和透明度反馈，松手后批量保存新顺序。
- 新增卡片追加到列表末尾；旧数据迁移时按现有稳定顺序生成初始排序值。
- Room 数据库从版本 7 迁移到版本 8，不清除已有卡片。

## 添加与编辑页面

- 页面使用可折叠分组：基础信息、显示内容、提醒设置、卡片颜色、渐变样式。
- 新建时默认只展开基础信息；编辑时同样保持清晰的单列滚动布局。
- “显示内容”顶部选择阳历、阴历或剩余时间，下方只展示该对象的一套年/月/日/时/分/秒开关。
- 阳历、阴历和剩余时间继续独立控制单位显示，不改变记录的实际日期时间。
- 页面保存按钮位于可滚动内容末尾，并保留足够底部间距，开启提醒后仍可到达。

## 颜色与渐变

- “卡片颜色”顶部选择卡片背景、标题、阳历、阴历或剩余时间，下方只显示当前对象的颜色编辑器。
- RGB 使用 R、G、B 三个独立数字框，范围 0 到 255。
- CMYK 使用 C、M、Y、K 四个独立数字框，范围 0 到 100。
- RGB 与 CMYK 双向同步；输入在失焦或确认时校正到合法范围，避免输入过程被自动重写。
- 保留实时预览、快捷色板和选中对号。
- “渐变样式”使用相同对象选择逻辑，并保留已内置的纯色、双色和 Aurora 样式。

## 品牌

- 桌面名称、Android 系统应用名称和应用顶部主标题统一为“时间规划局”。
- 使用用户提供的怀表图片制作 Android 自适应图标。
- 前景适当放大表盘，同时保留顶部表冠并确保圆形、方圆形等系统蒙版下不被裁掉。

## 数据与状态

- 卡片业务数据及 `sortOrder` 由 Room 保存。
- 全局显示设置和底部导航外观由 SharedPreferences 保存。
- 页面路由保留在 Compose 状态中；新增、编辑、返回和底部切换不会覆盖已有卡片。
- 保存新记录时必须使用新建语义；只有编辑已有记录时才携带原 ID 更新。

## 验证标准

- 三个底部入口可切换到对应独立页面，新增记录不会覆盖旧记录。
- 每个导航入口可改文字、换图标、隐藏其中一个元素，但不能变成空白入口。
- 长按拖动可调整顺序，重启应用后顺序不变。
- RGB/CMYK 可分别输入并正确同步，选择状态有对号。
- 编辑页面所有分组可展开、收起和完整滚动，保存按钮始终可到达。
- 应用名称和自适应图标正确显示。
- 已有数据库可从版本 7 升级到版本 8且记录不丢失。
- Kotlin 编译及 Debug APK 构建成功；对可独立测试的换算、设置和排序逻辑增加单元测试。

## 范围限制

- 本轮不增加云同步、账号、桌面小组件或新的提醒类型。
- 不允许用户改变三个底部入口的功能和位置，只允许改变展示方式。
- 不重写现有农历换算和倒计时核心算法，除非验证发现本轮改动造成回归。
