# 时间规划局交互审计

## 目标

将应用调整为接近系统工具类应用的三层信息结构：日常浏览快速、添加记录专注、设置可扫读且可回溯。

## 当前主要问题

1. 时间首页同时常驻搜索、多个筛选、置顶分区与全部记录，首屏缺少明确主任务。
2. 添加与编辑页在“内容、样式、提醒”之外继续嵌套多组展开内容，日期、显示控制与颜色配置的层级过深。
3. 我的页只有设置入口，无法提供记录概览或常用操作。
4. 设置列表只有功能名称，无法直接看出当前日期格式、导航显示或数据状态。
5. 长按排序和删除等高影响操作缺少持续、明确的状态反馈。

## 改造方向

### 时间

- 顶栏只保留页面标题、记录数量和搜索入口。
- 筛选收敛为“全部、即将到来、已开始”三项分段控件。
- 搜索按需展开；空状态提供明确添加动作。
- 排序时显示拖动提示与卡片占位反馈。

### 添加与编辑

- 用“基础信息 / 显示与样式”两步分段控制替代多层同级展开区。
- 第一步完成类型、名称、历法、日期与时间；第二步统一处理显示开关、提醒和颜色。
- 保留底部保存区，并加入实时卡片预览与缺失项提示。

### 我的

- 展示总记录、即将到来、已开始三个概览数据。
- 保留一个明确的设置入口，避免和设置页功能重复。

### 设置

- 维持显示与格式、底部导航、数据与备份、应用更新四类。
- 每个入口显示当前摘要，而非只显示功能名称。
- 底部导航按单个入口编辑，集中处理图标与文字显示逻辑。

## 不在本轮范围

- 不改变现有记录与设置的数据结构。
- 不发布 GitHub Release 或在线更新。
